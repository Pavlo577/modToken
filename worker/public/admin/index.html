Імпорт старих даних

      
Підтягне історію з локальних логів Claude Code (до прив'язки пристрою) і Codex (уся). Файли читає твій браузер, на сервер іде лише кількість токенів, час і модель, текст розмов не передається. Повторний імпорт безпечний: дублікатів не буде.

      

      
Вибери папку ~/.claude/projects для Claude або ~/.codex/sessions для Codex (на Windows %USERPROFILE%\...) і пристрій, якому вона належить. Для сервера без браузера на самому сервері виконай /tracker-import.
