Імпорт історії

      
Додай токени зі старих сесій Claude Code, які були до підключення OpenTelemetry. Файли читаються лише в браузері; на сервер йдуть тільки числа, назва моделі та id, без тексту розмов. Повторний імпорт нічого не дублює.
